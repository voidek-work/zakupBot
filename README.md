# 🚗 Telegram-бот для закупок и снабжения автосервиса

Специализированный бот на **Node.js (TypeScript)**, **PostgreSQL (Prisma)** и **Google Таблицах** для автоматизации процесса заявок на закупки, учета регулярных расходников цеха и прозрачной аналитики расходов.

---

## 🌟 Основные возможности

### 1. 👷 Для автомехаников и мастеров:
- **Пошаговая подача заявки (FSM-визард):** Категория ➡️ Рабочий пост ➡️ Наименование ➡️ Количество ➡️ Примерная цена ➡️ Обоснование ➡️ Ссылка на товар ➡️ Фото поломки/образца.
- **Выбор срочности:**
  - `🔴 СРОЧНО (Горит пост / машина висит на подъемнике)` — моментальный пуш завхозу со звуком.
  - `🟡 Планово (В еженедельную закупку)` — отправка в сводный список на неделю.
- **Раздел «Мои заявки»:** Онлайн-статусы, факт. цены, причины отказов и сроки поступления.
- **Кнопка «⚡ Быстрый расходник»:** Заказ в 1 клик (очиститель тормозов, WD-40, перчатки нитрил L/XL, чистик).
- **Подтверждение получения:** Кнопка «✅ Получил на руки» при доставке товара на склад.

### 2. 📦 Для завхоза / снабженца:
- **Интерактивные карточки действий:** Кнопки `[🟢 В работу]`, `[🛒 Заказано]`, `[📦 Доставлено на склад]`, `[🔴 Отклонить]`, `[💬 Автор]`.
- **Шаблоны причин отказа:** Быстрый выбор («Есть на складе», «Аналог на другом посту», «Не согласовано» и т.д.) или свой текст.
- **Фиксация фактических расходов:** Ввод фактической цены, ориентировочного срока и прикрепление фото чека/накладной.
- **Управление каталогом регулярных расходников:** Добавление и настройка мыла, смазок, перчаток, ветоши, кофе.
- **Пятничный чек-лист обхода цеха (Инвентаризация):** Интерактивный опросник по расходникам с автогенерацией сводного листа закупки на понедельник.

### 3. 👑 Для руководства и бухгалтерии:
- **Двусторонняя реалтайм-синхронизация с Google Таблицами:** Каждая заявка, статус, цена и срок мгновенно записываются в таблицу.
- **Автоматический еженедельный дайджест:** Каждое утро понедельника сводка плановых закупок с общей суммой.

## 🚀 Быстрый старт

### 1. Клонирование и установка зависимостей
```bash
cd c:/Users/voidek/projects/zakupBot
npm install
```

### 2. Настройка переменных окружения
Скопируйте файл `.env.example` в `.env`:
```bash
cp .env.example .env
```

Заполните ключевые параметры в `.env`:
```env
# Токен бота от @BotFather
BOT_TOKEN="123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ"

# Подключение к PostgreSQL
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/zakup_bot?schema=public"

# Telegram ID завхозов и руководства (через запятую)
MANAGER_TELEGRAM_IDS="123456789,987654321"
DIRECTOR_TELEGRAM_IDS="123456789"

# Порог согласования крупных сумм (в лари)
APPROVAL_THRESHOLD_GEL=200

# Интеграция с Google Sheets (опционально)
GOOGLE_SPREADSHEET_ID="your_google_sheet_id"
GOOGLE_SERVICE_ACCOUNT_EMAIL="your-service-account@iam.gserviceaccount.com"
GOOGLE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"

# Расписание CRON (Дайджест в Пн 10:00, Чек-лист в Пт 16:00)
CRON_WEEKLY_DIGEST="0 10 * * 1"
CRON_REGULAR_CHECKLIST="0 16 * * 5"
```

### 3. Инициализация базы данных и сиды
Примените схему к базе данных и загрузите стандартный каталог категорий и расходников автосервиса:
```bash
# Синхронизация схемы БД
npx prisma db push

# Наполнение базовыми категориями и расходниками цеха
npm run prisma:seed
```

### 4. Запуск и управление через PM2
Для надежной работы 24/7 с автоматическим перезапуском при сбоях:
```bash
# Сборка проекта
npm run build

# Запуск процесса в PM2
npm run pm2:start

# Перезапуск бота
npm run pm2:restart

# Просмотр логов в реальном времени
npm run pm2:logs

# Просмотр статуса процесса
npm run pm2:status

# Остановка бота
npm run pm2:stop
```

Для локальной разработки:
```bash
# Режим разработки (с tsx watch)
npm run dev

# Запуск тестов
npm test
```

## 📊 Интеграция с Google Таблицами

1. Создайте сервисный аккаунт в [Google Cloud Console](https://console.cloud.google.com/) и включите **Google Sheets API**.
2. Создайте новую Google Таблицу и выдайте сервисному аккаунту права **Редактора** (через кнопку «Поделиться»).
3. Укажите ID таблицы и данные ключа в `.env`. Бот автоматически создаст вкладки **«Заявки»** и **«Регулярные расходники»** с правильными заголовками.

## 🚀 Автоматический деплой через GitHub Actions

В репозитории настроен пайплайн CI/CD ([.github/workflows/deploy.yml](.github/workflows/deploy.yml)):
1. **CI этап:** при каждом пуше запускаются проверка типов (`tsc`), запуск всех тестов (`vitest`) и тестовая сборка.
2. **CD этап:** при пуше в ветку `main`/`master` происходит автоматическое подключение по SSH к вашему серверу, обновление кода, миграция БД, пересборка и горячий перезапуск процесса в **PM2**.

### Настройка GitHub Secrets
В настройках вашего репозитория на GitHub (**Settings -> Secrets and variables -> Actions -> New repository secret**) добавьте следующие переменные:

| Секрет | Описание | Пример |
|---|---|---|
| `SERVER_HOST` | IP-адрес или домен вашего сервера (VPS) | `194.87.12.34` |
| `SERVER_USER` | Имя пользователя на сервере | `root` или `ubuntu` |
| `SERVER_SSH_KEY` | Приватный SSH ключ (Ed25519 / RSA) | `-----BEGIN OPENSSH PRIVATE KEY----- ...` |
| `SERVER_SSH_PORT` | Порт SSH (опционально, по умолчанию 22) | `22` |
| `PROJECT_PATH` | Абсолютный путь к папке проекта на сервере | `/var/www/zakupBot` |

## 📁 Структура проекта

```text
zakupBot/
├── prisma/
│   ├── schema.prisma              # Модели PostgreSQL (User, Request, RegularItem, AuditLog, Category)
│   └── seed.ts                    # Каталог инструмента, химии и расходников
├── src/
│   ├── config/                    # Валидация env, константы постов и статусов
│   ├── db/                        # Клиент Prisma
│   ├── bot/
│   │   ├── context.ts             # Типизация сессий, FSM и ролей
│   │   ├── middlewares/           # Аутентификация и автоопределение ролей
│   │   ├── conversations/         # Пошаговые FSM-визарды (новая заявка, отказ, заказ)
│   │   ├── keyboards/             # Reply и Inline клавиатуры
│   │   └── handlers/              # Обработчики для механиков, завхоза и расходников
│   ├── services/
│   │   ├── requestService.ts      # Бизнес-логика заявок и история изменений
│   │   ├── regularService.ts      # Управление каталогом расходных материалов
│   │   ├── googleSheetsService.ts # Синхронизация с Google Sheets
│   │   ├── notificationService.ts # Мгновенные пуши, дайджесты и опросы
│   │   └── schedulerService.ts    # Планировщик cron
│   └── index.ts                   # Точка входа приложения
├── package.json
└── tsconfig.json
```
